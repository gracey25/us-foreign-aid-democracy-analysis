# U.S. DRG Assistance and Democratic Change, 2001–2024

Author: Grace Young

Report: [Read the research report](outputs/research_report.pdf)

## 1. Project overview

> This project explores the relationship between U.S. foreign assistance in the Democracy, Human Rights, and Governance (DRG) sector and democratic changes in recipient countries between 2001 and 2024. It combines V-Dem democracy measures with ForeignAssistance.gov obligation data to examine distributions, global trends, regime-type differences, and within-country associations. The analysis is exploratory and does not establish causal effects.

## 2. Data sources and documentation

- V-Dem: Country-Year Core Dataset, version 16, https://doi.org/10.23696/vdemds26.
- ForeignAssistance.gov: USG Sector Summary, downloaded September 24, 2026, https://foreignassistance.gov/data.
- Raw inputs: `data/raw/` contains the V-Dem input subset and the ForeignAssistance.gov dataset.
- Cleaned panel: `data/processed/` contains the cleaned, merged country-year panel used for analysis.
- Data dictionary: `DATA_DICTIONARY.md`, in the repository root, explains the variables and their meanings.

The V-Dem file in `data/raw/` is a preprocessed subset, not the complete original download. Because the original CSV was large, I uploaded it from my local computer to Google Colab and reduced it using `notebooks/00_vdem_preprocessing.ipynb`.

I retained observations from 1999–2024 and the following columns:
- `country_name`
- `country_text_id`
- `year`
- `v2x_polyarchy`
- `v2x_libdem`
- `v2x_cspart`
- `v2x_regime`

The additional years 1999–2000 support construction of lags for the analysis period beginning in 2001.

The ForeignAssistance.gov file in `data/raw/` is unchanged from the downloaded dataset. Subsequent filtering, cleaning, and aggregation are documented in the analysis notebooks.

## 5. How to reproduce the analysis

1. Download or clone this repository.
   Review the repository structure, software requirements, and
   `DATA_DICTIONARY.md` before running the notebooks.

2. Open the cleaning notebook in Google Colab.
   Upload `notebooks/01_data_cleaning.ipynb` to Colab and connect
   to a Python runtime.

3. Check the dependencies.
   Confirm that the runtime contains the package versions listed
   under Software Requirements. 

4. Run the cleaning and merging notebook from top to bottom.
   Execute every cell in `01_data_cleaning.ipynb` in order. This
   notebook filters and cleans the input data, creates lagged
   democracy variables, aggregates DRG obligations, and produces
   the merged analysis panel.

   The included V-Dem subset is sufficient for this step.
   `notebooks/00_vdem_preprocessing.ipynb` is optional and requires
   the original full V-Dem download.

5. Open and run the analysis notebook.
   Upload `notebooks/02_eda_visualizations.ipynb` to Colab and
   execute every cell in order. Confirm that its data-loading step
   reads the panel regenerated in Step 4. 

6. Locate and save the outputs.
   Review the descriptive statistics, correlations, and statistical
   results displayed in the analysis notebook. Download the
   regenerated cleaned panel and saved figures from Colab, then
   place them in the corresponding repository folders:

   - `data/processed/`: cleaned and merged analysis panel
   - `outputs/figures/`: saved visualizations

   Colab’s runtime files are separate from the GitHub repository;
   running the notebooks does not automatically update GitHub.

7. View the final report.
   `outputs/research_report.pdf` contains the written analysis.
   I assembled this report manually in Google Docs and exported it as
   a PDF. Running the notebooks regenerates the analytical outputs,
   not the report document.

Runtime has not been benchmarked.

## 6. Key Processing Decisions and Limitations

- Analysis scope: I restrict the analysis to 2001–2024 obligations in
  the Democracy, Human Rights, and Governance (DRG) sector.

- Aid aggregation: I sum obligations by country and fiscal year and
  express inflation-adjusted amounts in millions of U.S. dollars.

- Data linkage: I outer-join the datasets using country codes and
  year labels. V-Dem uses calendar years, whereas U.S. fiscal years
  run from October through September; matching year labels does
  not align identical reporting periods.

- Missing democracy scores: I fill three missing liberal-democracy
  scores using forward fill followed by backward fill, assuming
  short-term continuity. These imputed values may obscure actual
  changes in democratic performance.

- Legacy records: I exclude seven small Czechoslovakia records
  lacking country codes because the dissolved state does not match
  the V-Dem identifiers during the analysis period. Their likely
  interpretation as accounting adjustments remains unverified.

- Missing aid: I replace missing aid values after merging with zero,
  assuming absent records indicate no obligations. This may
  misclassify unreported funding as zero aid.

- Lagged and demeaned variables: I generate one-year
  democracy lags within countries. For within-country comparisons,
  I subtract country-specific means from the relevant democracy
  and logged-aid variables.

- Log transformation:
  - Aid histogram: I plot `log10(aid_millions)` using only strictly
    positive obligations. Zero and negative values are excluded
    from this histogram.
  - Within-country scatterplots: I create
    `log_aid = log10(aid_millions + 1)` before demeaning.

- Interpretation: The analysis identifies descriptive patterns and
  associations, not causal effects. 

## 7. Key findings

- Aid is strongly right-skewed, with large differences between mean and median allocations.
- Median aid is highest for electoral autocracies and electoral democracies.
- Global annual aid totals show no clear relationship with global average democracy scores.
- Within-country lagged democracy measures show weak positive associations with logged aid, but explain little variation and do not establish causality.
